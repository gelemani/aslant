# aslant

**Clear glass that writes in sunlight.**

Лендинг вымышленной студии Aslant, которая рассчитывает и фрезерует прозрачные оконные стёкла. Поверхность стекла посчитана так, что в выбранный час солнце пишет на стене слово. Студия придумана, свет настоящий: каустика слова считается прямо в браузере.

Сайт устроен как одна комната в течение одного дня. Скролл двигает солнце от 08:10 до 20:40: пятно света ползёт по стене, теплеет и в полдень переходит на другую сторону, а в финале догорает угольком.

## Запуск

```bash
npm install
npm run dev                         # http://localhost:3000
npm run build && npx next start -p 3456   # production (порт 3100 занят проектом InColor)
```

## Главы

| Час | Глава | Что происходит |
|---|---|---|
| 08:10 | First light | Заставка-рассвет. Слово *aslant* собирается из бликов, как свет на дне бассейна. Курсор работает как солнце |
| 10:30 | Clear glass | Стекло выглядит прозрачным. Лупа (шлирен-метод Тёплера, 1864) показывает спрятанный в нём рельеф |
| 12:50 | The bend | Оптическая скамья: плоское стекло, рельеф, дисперсия. Лучи можно выбирать мышью, касанием или стрелками |
| 16:12–17:08 | The appointment | Часы идут вместе со скроллом. Слово *Ingrid* складывается ровно в 16:40 и снова рассыпается |
| ваш час | Write yours | Ваше слово (есть кириллица и латиница с диакритикой), ваш город, ваш час. Стекло считается на глазах, картинку можно сохранить |
| 18:20 | Precedent | Две тысячи лет прецедентов: от бронзовых зеркал династии Хань до работы EPFL 2014 года |
| 19:10 | Commission | Форма заказа на освещённом участке стены |
| 20:40 | Dusk | Подвал с угольком. Эпилог с послеобразом: цвет, которого нет на экране, дорисовывает ваш глаз |

Горячая клавиша **L** убирает весь текст из комнаты, остаются только стена и свет.

## Как считается свет

- **Транспорт света.** Растр слова и равномерная сетка лучей (последовательность R2, 65 536 лучей) сопоставляются через sliced optimal transport (сортировка проекций), в Web Worker. Кадры отдаются потоком, поэтому видно, как стекло «досчитывается».
- **Рельеф стекла** получается интегрированием поля наклонов (Пуассон, сопряжённые градиенты). Глубина и крутизна, которые показываются на странице, взяты из расчёта, а не вписаны руками.
- **Спектр.** 8 полос длин волн, дисперсия по Коши и наблюдатель CIE 1931. Цветная кайма на краях букв физическая.
- **Солнце.** Позиция по алгоритму NOAA для 44 городов. `npm test` проверяет модель по тестовым векторам: окно 16:30–16:50, сезон с 26 мая по 19 июля, закаты.
- **Рендер.** Один фиксированный R3F-canvas с `frameloop="never"` и одни часы (`gsap.ticker`): Lenis, затем ScrollTrigger, затем conductor, затем DOM, затем кадр. Рендер идёт только при изменениях, после 10 с без ввода рендер останавливается. Качество регулирует свой governor.
- **Комната.** Известковая штукатурка, шум фотонов вместо наложенного зерна, полутень от солнечного диска, тени переплёта, пылинки в луче. Тень на стене откалибрована под токен `#3A4142` с точностью до 2 уровней.

## Режимы и флаги URL

| Флаг | Что делает |
|---|---|
| `?motion=reduced` | Still air: без плавного скролла и анимаций, всё содержимое на месте |
| `?webgl=0` | Overcast: без WebGL, постеры и CSS-свет |
| `?tier=2` | Облегчённое качество, как на телефоне |
| `?still=<глава>` / `?still=og` | Замороженный кадр главы (для постеров и OG) |
| `?word=Имя` | Предзаполняет слово в Write yours |
| `?qa` | HUD и `window.__aslant` (в dev включён всегда) |

Переключатели Still air и Overcast есть в меню и в подвале.

## Форма заказа

Форма работает честно, режим выбирается переменными окружения при сборке:

- `NEXT_PUBLIC_COMMISSION_ENDPOINT` — JSON POST; «успех» показывается только при ответе 2xx.
- `NEXT_PUBLIC_COMMISSION_EMAIL` — заполненное письмо (`mailto:`).
- без переменных (сейчас) — preview: сеть не трогается, пишется «Commissions open in spring 2027. Nothing was sent.», а слово складывается в свете панели.

## Скрипты

| Команда | Назначение |
|---|---|
| `npm test` | модель солнца против тестовых векторов |
| `npm run bake` | пересчёт `public/light/*.bin` (Python + numpy) |
| `npm run capture` | постеры и OG-картинка с живого рендера (нужен `next start -p 3456`) |
| `npm run check:copy` | копирайт: тире, запрещённые слова, дословность финального текста |
| `npm run check:contrast` | контраст текста по реальным пикселям каждой главы и переходов |

## Как это делалось

Всё лежит в `docs/`:

1. `docs/process/01–06` — исследование: тренды 2026 года, разбор 17 сайтов-победителей Awwwards, FWA и CSSDA, шрифты и палитры с проверкой лицензий, техники под этот стек, свод правил из дизайн-скиллов, список признаков «AI-slop».
2. `docs/process/concepts/` — 6 концепций от разных «креативных директоров» (свет, живая материя, время и звук, типографика, wildcard, «ночь»). Их оценивали три судьи с разными критериями. Победил свет, у концепции есть Python-прототипы и референсные рендеры.
3. `docs/BRIEF.md` — итоговый бриф на ~41 тыс. слов: копирайт, токены, архитектура, контракты, 11 рабочих пакетов со строгим владением файлами, гейты QA G0–G5. Его прошли два критика, найденные 52 замечания исправлены.
4. Сборку вели 11 параллельных агентов (движок света, транспорт, conductor, главы, края, независимый QA). Координировались через почтовые ящики в файлах; спорные решения записаны в журнал решений.

## Честность

*Aslant is a proposal for a studio. The light is real.* Выдуманы студия, её копенгагенский адрес, первая партия, размеры и сроки, а также имя Ingrid. Настоящие: вся физика света, модель солнца и история в главе Precedent. Отзывов, логотипов, цен и «наград» на сайте нет.
