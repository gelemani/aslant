# Доброе утро

Проект теперь называется **aslant**. Это лендинг вымышленной студии, которая рассчитывает оконные стёкла так, чтобы солнце в выбранный час писало на стене слово. Сайт устроен как одна комната в течение одного дня, скролл двигает солнце. Каустика слова считается прямо в браузере, в том числе для слова, которое вы введёте сами.

Запуск:

```bash
npm run dev                                  # http://localhost:3000
npm run build && npx next start -p 3456      # production (порт 3100 занят проектом InColor)
```

Что посмотреть:
- Покрутить сайт от начала до конца: свет проходит день с 08:10 до 20:40.
- В главе «Write yours» ввести своё имя (кириллица тоже работает) и сохранить картинку.
- Нажать **L**, чтобы убрать текст из комнаты.
- Режимы `?motion=reduced` (без анимаций) и `?webgl=0` (без WebGL). Переключатели для них есть в меню.

Форма заказа по умолчанию работает в честном режиме preview: никуда ничего не отправляет и так и пишет. Для настоящей отправки задайте `NEXT_PUBLIC_COMMISSION_ENDPOINT` (POST) или `NEXT_PUBLIC_COMMISSION_EMAIL` (mailto). Для деплоя задайте `NEXT_PUBLIC_SITE_URL`, чтобы OG-ссылки указывали на реальный домен.

Исследование, турнир концепций, итоговый бриф и журнал решений лежат в `docs/`, подробности в `README.md`. Если папки `.next` нет, один раз выполните `npm run build`.
